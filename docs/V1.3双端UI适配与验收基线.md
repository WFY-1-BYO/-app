## 0. 本次需求与决策

用户要求：「在 App 的两种移动端，UI 设计就参考这个文档修改」。两种移动端指 **vivo S7 手机** 与 **联想拯救者 Y900 安卓平板**。

| 编号 | 决策 | 说明 |
| --- | --- | --- |
| D1 | **手机首页保持 V1.2「极简一屏」** | 用户在 V1.2 确认问题时明确选择「极简一屏」，理由是首页下滑内容太多。故不按图 3 恢复「今天三餐 / 今日运动 / 七日同桌」等下滑区块 |
| D2 | **平板按图 14 / 15 做左侧导航 + 双栏** | 平板空间充足，用分栏承载副信息，不靠下滑堆砌；这不算推翻 D1 |
| D3 | **运动相关内容继续全删** | 图 14 的「今日运动」卡、图 15 的「运动」分类与「运动记录」历史项、图 2 的「运动计划」流程均不实现，遵守 V1.2 第 4 点 |
| D4 | 断点取 **CSS 宽度 ≥ 900px** 为平板布局 | vivo S7 逻辑宽度约 360–411px；Y900 逻辑宽度约 1280px。≥900px 覆盖平板横屏，不误伤手机 |
| D5 | 分栏默认 **16:10 优先**，主栏 : 副栏 ≈ 1.6 : 0.9 | 对应图 14/15 的宽屏比例；副栏最小 280px，窄于阈值时自动回退单列 |
| D6 | 悬浮球默认停靠边记忆沿用 V1.2 实现 | 文档第十节「是否记忆」为待确认项，V1.2 已实现拖动后记忆位置，继续沿用 |
| D7 | 每次改动后测试并提交推送 | 遵守 V1.2 第 10 点与用户「从现在开始，每次改动都要将源代码提交到 GitHub」 |

## 3. 无障碍与动效

- 触控目标 ≥ 44dp；系统字体放大不清空布局；`prefers-reduced-motion` 下关闭非必要动效。
- 动效只用于页面反馈、角色表情、勋章点亮三处，1–2 秒，不强制全屏、不阻断操作。
- 图表图例必须带克数 + 百分比；供能环中心显示总能量。

## 4. 验收清单

### 改编 A：平板左侧导航栏
- [ ] ≥900px 时渲染左侧固定竖排导航，不显示顶部 sticky 横条。
- [ ] 三个入口文案为「今天 / 记录 / 我的」，各带副标题与线性 SVG 图标。
- [ ] 选中项有浅灰绿底与视觉标记；底部显示版本与「数据存于本机 / NDM 可导出迁移」。
- [ ] 手机宽度下仍为底部三段导航，且隐藏左侧导航。
- [ ] 导航项可点击跳转，路由高亮正确。

### 改编 B：首页平板双栏
- [ ] 平板首页存在主栏与副栏两个区域；主栏含下一餐卡片与唯一「拍照配餐」主 CTA。
- [ ] 副栏含「营养师说」「坚持进度」「健康指标」三个模块。
- [ ] 手机首页仍只有一个 `.cta-primary`，且不出现三餐状态、坚持统计、健康提醒、运动字样。
- [ ] 平板首页不出现「运动」字样。
- [ ] 副栏健康指标只做摘要与就医提醒，不诊断。

### 改编 C：记录页平板双栏
- [ ] 平板记录页左栏为坚持统计四项 + 历史列表，右栏为选中日详情。
- [ ] 右栏含供能环（中心总能量）、三大营养素克数 + 百分比、四态判定、知夏说明、近 14 天趋势。
- [ ] 点击左栏某天可切换右栏详情。
- [ ] 手机记录页保持单列，原有功能与文案不丢失。
- [ ] 不出现「运动」分类或「运动记录」历史项。

### 改编 D：Design Tokens 统一
- [ ] 色板仅 6 色，移除红色失败变量与 `.button.danger`。
- [ ] 字阶、卡片圆角、主 CTA 高度、次按钮样式符合第 2 节。
- [ ] 图标为线性 SVG（非 emoji），触控目标 ≥ 44dp。
- [ ] 悬浮球手机 56dp / 平板 64dp，且平板下避开左侧导航。
- [ ] 存在 `prefers-reduced-motion` 降级规则。

### 全局
- [ ] 每个改编后 `pnpm typecheck && pnpm lint && pnpm test && pnpm build` 全绿，且提交推送到 GitHub。
- [ ] 全部改编后再跑一次全量回归。
- [ ] 测试不降低标准、不跳过；不因 UI 改动删改既有业务断言。
- [ ] 线上重新发布需用户单独授权，不擅自覆盖 V1.1 在线版。

## 5. 边界说明

- 本轮只做**双端布局与视觉规范**，不改动配餐、NDM、健康上传、AI 密钥等既有业务逻辑。
- 图 11/12/13 的立绘与九组表情为设计稿参考，第一版仍用静态头像 `/assistant.svg`，不引入 Live2D / 语音。
- 文档第十节待确认的「立绘与勋章图案是否用于对外宣发」不在本轮范围，不影响代码。
