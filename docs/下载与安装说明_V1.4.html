家庭营养师 V1.4 · 下载与安装

形态：V1.4 同时提供安卓 APK与 PWA 网页版。APK 用 Capacitor 封装、自签名，可直接装到 vivo S7 / 联想 Y900，离线可用；网页版用在线 HTTPS 地址「添加到主屏幕」即可。两者功能一致，数据都只存在本机。

一、下载最新成品

family-nutritionist-v1.4.0.apk（约 3.5 MB，推荐）安卓安装包，传到手机 / 平板点击安装即可。包名 com.family.nutritionist，版本 1.4.0，最低 Android 6.0。 family-nutritionist-v1.4.zip（约 1 MB，网页版）含完整生产构建、一键启动脚本、使用说明。解压即用，也可部署到任意静态服务器。 Release 页面（两个文件都在这里）Release v1.4.0，可查看更新说明与全部资产。
打开在线最新版 查看源码仓库

二、安装安卓 APK（推荐）

  1. 下载 family-nutritionist-v1.4.0.apk，用数据线、微信文件传输或网盘传到手机 / 平板。
  2. 点击安装。系统提示「未知来源应用」时，允许本次安装（文件管理器 / 浏览器来源）。
  3. 桌面出现「家庭营养师」图标，点开即用，无需联网。
  4. 首次用到语音录入会申请麦克风权限、拍照会调用系统相机，按提示允许即可。

说明：APK 使用自签名证书。今后我要发新版时，必须用同一份证书签名才能直接覆盖安装；换证书需先卸载旧版（会清空 App 内数据，请先导出 .ndm.md）。

三、在电脑上运行网页版

  1. 把 zip 完整解压到一个固定文件夹（不要只解压单个文件）。
  2. Windows 双击 启动-Windows.bat；macOS / Linux 运行 启动-Mac-Linux.command（需 Python 3）。
  3. 浏览器打开 http://localhost:8080 即可使用。同一 WiFi 下手机 / 平板可访问启动时打印的局域网地址临时查看。

四、把网页版装到 vivo S7 / 联想 Y900 桌面

  1. 手机 / 平板浏览器打开上方「在线最新版」的 HTTPS 地址。
  2. 浏览器菜单选 「添加到主屏幕」/「安装应用」。
  3. 桌面出现「营养师」图标，点开即全屏 App，断网也能打开。

注意：浏览器要求 HTTPS 才允许安装，局域网 http 仅供临时查看，不能安装。这是浏览器安全规则。

六、V1.4 更新内容（13 项）

  • 档案：出生日期改为「年 / 月 / 日」直接填写；日常活动水平用生活场景解释；口味支持自定义添加 / 移除。
  • 配餐：照片支持「拍摄 + 相册上传」双入口；手动添加食材的用量框标注「克」并给出常见参照；配餐结果可让知夏做 AI 点评。
  • 记录与我的：「我的」重排为档案卡 + 四项统计 + 分组入口；勋章达成时全屏播放点亮动画。
  • 健康：删除全部语音转文字按钮；健康文件可选择上传，文字类文件支持 DeepSeek 在线抽取指标。
  • 数据：导入导出显示进度、结果摘要与失败原因，坏文件如实报错。
  • 体验：悬浮球可自由拖动并记忆位置，每天首开自动播报今日知识；知夏头像与表情按 UI 设计文档落地；Service Worker v4。
