## 1. 视觉规范（沿用 UI 方案 V1.1 Design Tokens，不新增彩色）

| 用途 | 值 |
| --- | --- |
| 页面背景 | `#FAFAF7` 暖白 |
| 主色 | `#708B74` 鼠尾草绿 |
| 主要文字 | `#292D2A` |
| 次要文字 | `#7A807B` |
| 奖励点缀 | `#E7A56F` 柔橙 |
| 分割线 | `#E4E8E2` |

- 卡片：圆角 16、描边 1px、双层极轻阴影、内边距 13–16。
- 主 CTA：高 56dp、鼠尾草绿实心、**首页唯一主行动**。
- 状态一律「文字 + 图形」双通道；禁止红色失败标记与批评文案。
- 图表：饼图只画三大营养素供能比，中心显示总能量，图例带克数 + 百分比。
- 悬浮球「知夏」：手机 56dp / 平板 64dp，仅 App 内，专注页隐藏。

## 2. 首页（改动 1）验收要点

- [x] 首屏自上而下只有 4 块：日期与目标（一行）、下一餐卡片、唯一主按钮「拍照配餐」、营养师说知识气泡。
- [x] 首页不出现三餐状态、坚持统计、勋章进度、健康提醒、运动字样。
- [x] 上述被移走的内容在「记录」页仍可查看（不丢失功能，仅调整层级）。
- [x] 悬浮球在非专注页可见，专注页隐藏。
- [x] 无档案时显示建档引导，有档案时直接显示首页。

## 3. 勋章墙（改动 2）验收要点

- [x] 每枚勋章有独立 SVG 图案（小碗、勺子、新芽、星星、四季之一）。
- [x] 已点亮：柔橙或鼠尾草绿实心搪瓷圆形徽章 + 点亮日期。
- [x] 未点亮：虚线圆 + 灰色线稿 + 达成条件 + 进度条。
- [x] 顶部说明「不奖励每餐完美、中断不清零」。
- [x] 分组不再包含「运动」。

## 4. 运动删除（改动 3+4）验收要点

- [x] 代码中不存在 `/exercise` 路由、`Exercise.tsx`、`lib/exercise.ts`、`exercise.test.tsx`。
- [x] `types.ts` 不含 `ExerciseLog`/`ExerciseStatus`/`ExerciseSource`/`MealSession.exerciseContext`；`MedalGroup` 不含 `exercise`。
- [x] `AppData` 不含 `exerciseLogs`；store 不含 `addExerciseLog`/`updateExerciseLog`。
- [x] NDM 导出不含「运动记录」段，导入遇到旧运动段应安全忽略而非报错。
- [x] 各页面、知识库、勋章、文案中不再出现「运动」字样（含「过量运动补偿」等措辞）。
- [x] 「运动记录」统计项从记录页移除。

## 5. 档案回填（改动 5）验收要点

- [x] 已有档案时再次打开 `/onboarding`，各字段预填原值。
- [x] 保存后 `id`、`createdAt` 保持不变，`updatedAt` 更新。
- [x] 「我的」页档案入口文案明确为编辑，不出现空白表单。

## 6. 参照物（改动 6）验收要点

- [x] 提供参照物选择：银行卡/身份证（85.6×54mm）、可打印棋盘参照卡（100×100mm）、已校准碗盘、无参照物。
- [x] 拍摄指引写明：同平面、完整入镜、无遮挡、俯视 45°–90°，不强制垂直。
- [x] 说明四角透视校正原理，倾斜照片可被拉正为俯视图。
- [x] 三级降级：A 给克重区间；B 结合已校准餐具；C 只识别品类与份数并强制确认。
- [x] 输出含「高可信 / 需确认」标记与估算区间，确认后才用于配餐。
- [x] 无 key 时参照物仍可用于本地校准估算。

## 7. 知识日历（改动 7）验收要点

- [x] 每天只推一条，同一天不重复。
- [x] 按日期归档，第 2 天可查看第 1 天。
- [x] 知识册提供日历视图，点某天显示当天知识。
- [x] 保留分类筛选、展开「为什么」、收藏、已读。

## 8. 健康数据录入（改动 8）验收要点

- [x] 主入口为拍照/文件上传，支持语音转文字（浏览器能力，不可用时降级提示）。
- [x] 无 key 时上传只留档并标记「待识别」，不假装已识别。
- [x] 填入 key 后「待识别」记录可自动重新识别，不需重新上传。
- [x] 手动录入保留为兜底，不删除。
- [x] 已确认的数值仍给出趋势与评价，异常提示就医，不诊断。
- [x] 上传附件以文件名关联，不把图片二进制塞进 NDM 正文。

## 9. AI 密钥（改动 9）验收要点

- [x] 接口地址内置，设置页只填一次 key。
- [x] key 加密后存本地，界面不明文回显，输入框为密码类型。
- [x] 无 key 时所有 AI 功能降级为本地规则，App 不报错、不阻塞。
- [x] 有 key 时启用在线识别，状态可查。
- [x] 如实说明：纯前端方案下密钥仍可能被提取，不是服务端级隐藏。

## 10. 测试与提交纪律

- 每完成一个改动，执行 `pnpm typecheck && pnpm lint && pnpm test && pnpm build`，**不降低标准、不跳过测试**。
- 通过后提交一次，提交信息标注改动编号。
- 全部改动完成后再执行一次完整回归，并验证线上入口。
- 公开仓库只提交源码与文档，绝不提交真实健康数据、`.ndm.md` 数据文件、密钥或附件。
