家庭营养师 V1.3 · 下载与安装

单人 · 双设备 · 本地存储 ｜ 最新构建 2026-11-14 ｜ 交付版本 v1.3.0
形态：V1.3 同时提供安卓 APK与 PWA 网页版。APK 用 Capacitor 封装、自签名，可直接装到 vivo S7 / 联想 Y900，离线可用；网页版用在线 HTTPS 地址「添加到主屏幕」即可。两者功能一致，数据都只存在本机。

一、下载最新成品

family-nutritionist-v1.3.0.apk（约 3.5 MB，推荐）安卓安装包，传到手机 / 平板点击安装即可。包名 com.family.nutritionist，版本 1.3.0，最低 Android 6.0。 family-nutritionist-v1.3.zip（约 230 KB，网页版）含完整生产构建、一键启动脚本、使用说明。解压即用，也可部署到任意静态服务器。 Release 页面（两个文件都在这里）Release v1.3.0，可查看更新说明与全部资产。
打开在线最新版 查看源码仓库

二、安装安卓 APK（推荐）

  1. 下载 family-nutritionist-v1.3.0.apk，用数据线、微信文件传输或网盘传到手机 / 平板。
  2. 点击安装。系统提示「未知来源应用」时，允许本次安装（文件管理器 / 浏览器来源）。
  3. 桌面出现「家庭营养师」图标，点开即用，无需联网。
  4. 首次用到语音录入会申请麦克风权限、拍照会调用系统相机，按提示允许即可。

说明：APK 使用自签名证书。今后我要发新版时，必须用同一份证书签名才能直接覆盖安装；换证书需先卸载旧版（会清空 App 内数据，请先导出 .ndm.md）。

三、在电脑上运行网页版

  1. 把 zip 完整解压到一个固定文件夹（不要只解压单个文件）。
  2. Windows 双击 启动-Windows.bat；macOS / Linux 运行 启动-Mac-Linux.command（需 Python 3）。
  3. 浏览器打开 http://localhost:8080 即可使用。同一 WiFi 下手机 / 平板可访问启动时打印的局域网地址临时查看。

四、把网页版装到 vivo S7 / 联想 Y900 桌面

  1. 手机 / 平板浏览器打开上方「在线最新版」的 HTTPS 地址。
  2. 浏览器菜单选 「添加到主屏幕」/「安装应用」。
  3. 桌面出现「营养师」图标，点开即全屏 App，断网也能打开。

注意：浏览器要求 HTTPS 才允许安装，局域网 http 仅供临时查看，不能安装。这是浏览器安全规则。

六、这一版包含什么

  • V1.2 九项改动：首页极简一屏、勋章样式、运动内容全删、档案回填、参照物方案、知识日历回看、健康拍照/语音录入、AI 密钥加密存储、GitHub 版本管理。
  • V1.3 双端 UI 适配：手机底部三段导航 + 极简一屏；平板左侧导航栏 + 首页/记录双栏；Design Tokens 统一。
  • 本次交付：补齐 192/512 与 maskable 安装图标、独立窗口清单、Service Worker v3 离线缓存；修复线上服务把图标误返回 HTML 的缺陷；配置 GitHub Actions 自动编译产出可下载包。
