家庭自用营养师 App · 页面结构与 UI 设计方案 V1.1（含界面图）
依据《家庭自用营养师 App 产品需求文档 V1.1》整理 ｜ 版本 V1.1（文字方案 + 全套界面图/设计图板）｜ 2026年11月12日
一、设计目标与原则
本产品定位为家庭自用的轻量饮食与营养助手，单用户、本地存储优先。整套界面围绕 PRD 第 6 章提出的四条体验硬原则展开，并把它翻译成可落地的界面规则：
温和：不使用红色失败标记、不清零、不催促；漏记日只保留中性格，计划外饮食不做弹窗警告，而用对话承接。
干净：单一主行动按钮、低饱和配色、克制留白；首页只放一个主按钮，其余动作全部下推到「记录」。
生活感：配色与「小碗、新芽、四季食材」一致，陪伴角色「知夏」承担解释与陪伴，不抢核心配餐流程。
专业但不冰冷：先肯定再建议、说清适用边界；涉及疾病只做辅助解释，异常提示就医，不做诊断。
二、视觉规范（Design Tokens）
全 App 只使用 PRD 给定的一组低饱和色板，不再新增彩色，避免视觉噪声与焦虑感。
色彩（6 色）：页面背景 #FAFAF7（暖白，不用复杂壁纸）；主色 #708B74（鼠尾草绿，主按钮、选中、图表主色）；主要文字 #292D2A（深灰）；次要文字 #7A807B（中灰，辅助说明）；奖励点缀 #E7A56F（柔橙，勋章、额外推荐、庆祝）；分割线 #E4E8E2（浅灰绿，描边 1px）。禁止红色失败色与批评文案连续落到提醒。
字阶与数字：优先系统无衬线，数字用 tabular-nums 对齐。能量大数字 28px，页面标题 22px，卡片主标题 19px，区块标题 16px，正文 14px/行高 1.5，辅助文字 12px，状态与标签 11px。
组件：卡片圆角 16、描边 1px #E4E8E2、双层极轻阴影，内元素圆角 12–14、卡内边距 13–16。主 CTA 高 56dp（唯一主行动，鼠尾草绿实心）；次按钮白底描边；奖励、轻松场景用柔橙。状态一律「文字 + 图形」双通道表达，不只靠颜色。
图表与勋章：饼图默认只画三大营养素供能比，中心显示总能量，图例必须带克数 + 百分比；趋势用堆叠柱状。勋章描瓷徽章风格，图案只用小碗、勺子、新芽、星星、四季，未点亮为低饱和线稿 + 条件 + 进度。

三、信息架构与导航
导航采用「主入口 3 个 + 二级非专注页 + 专注流程」的三层结构；知识不设独立 Tab，以角色气泡形式出现在首页。
主入口（3 个）：今天（下一餐、今天三餐、营养师说）、记录（日历 + 趋势 + 历史）、我的（档案、约束、校准、授权）。手机用底部三段导航，Y900 平板用左侧导航栏。
二级非专注页：配餐结果、菜谱详情、知识详情与知识册、勋章墙、记录详情、我的及普通设置——这些页面悬浮球可见。
专注流程（8 条，进入即自动隐藏悬浮球防误触）：首次引导（5 步）、拍照配餐、菜谱烹饪步骤、实际用餐确认、运动计划连续填写、健康指标手动填写、餐具校准、NDM 导入冲突处理。

四、核心页面结构
今天（首页）
自上而下：日期与目标 + 轻量坚持提示 →「下一餐」卡片（如「午餐还没安排」+ 建议时间与能量区间）→ 拍照配餐主按钮 → 今天三餐状态（早餐/午餐/晚餐）→ 营养师说气泡（今日知识，可展开「为什么」并收藏）→ 运动卡与勋章进度卡。同一餐不会反复弹提示。
图 3　今天（首页）· vivo S7 手机：下一餐卡片 + 单一主行动按钮 + 今天三餐状态 + 营养师说气泡
记录
顶部坚持统计四项（记录日 / 累计坚持日 / 当前连续 / 历史最长）→ 月历视图（记录日、坚持日、均衡日、休息日四态标记，漏记日为中性格）→ 饮食/运动/健康/勋章分类切换 → 近 7 天供能比例堆叠柱（同时给克数，不只靠颜色）→ 历史记录列表。
图 4　记录 · 手机：坚持统计四项、四态月历（漏记日为中性格）、供能比例堆叠柱、历史记录入口
我的
个人档案与饮食目标（减脂/增肌/维持健康）→ 过敏·忌口·口味 → 疾病与医生限制（只做饮食辅助、边界文案常驻）→ 餐具校准 → vivo 健康授权（未接入仍可手动与文件导入）→ 知识册 → 数据与备份（导出 .ndm.md）。
图 5　我的 · 手机：档案与饮食约束 / 校准与授权 / 数据与备份三组分组列表
勋章墙
顶部说明「奖励长期做得到的事，不奖励每餐完美，中断不清零」；分坚持系列与从容系列，已点亮用柔橙/鼠尾草绿描瓷徽章并标点亮日期，未点亮显示进度条，底部为「知夏·勋章寄语」气泡。
图 6　勋章墙 · 手机：坚持系列与从容系列，已点亮标日期、未点亮显示进度条，顶部说明「中断不清零」
首次引导
1/5「先建一个属于你的档案」：昵称、出生年份、身高、体重、日常活动量 → 饮食目标三选一 → 明确「本地保存为主，仅在主动使用识别/配餐/知识时发送最少内容，断网仍可查看全部本地记录」。
图 7　首次引导 1/5：档案字段 + 饮食目标三选一 + 本地保存为主的隐私说明，支持跳过稍后补
五、关键流程
主线·当次食材配餐
选择餐次 → 阅读拍摄指引 → 拍当次食材 + 参照物 → 确认识别食材与用量（逐项标注高可信/需确认，可手动修改）→ 生成只用当次食材的菜谱（单独展示，不混入食材库）→ 额外推荐单独成区、不参与本次计算 → 做法/营养估算/角色解释 → 实际用餐后确认记录。
图 8　主线第 3/4 步：确认食材与用量（逐项标注高可信/需确认，可手动修改）
图 9　配餐结果：菜谱 / 营养结构 / 额外推荐三块分离，额外推荐单独承载不入合计
支线·计划外饮食（与惩罚式管理相反）
普通入口或角色表达「想吃」→ 角色不批评回应 → 如实说明与目标差异 → 给出 A/B/C 三种选择（按原计划 / 正常吃并把当餐调轻 / 偶尔一次不做补偿）→ 用户自主决定 → 正常记录、成果不清零 → 下一餐回归「从容系列」。
图 10　支线·计划外饮食：角色不批评回应 → 如实说明差异 → A/B/C 三选一 → 正常记录不清零
六、陪伴角色「知夏」与悬浮球
「知夏」是悬浮球背后的营养师形象：25 岁成年女性感、浅栗棕低马尾、暖棕偏绿眼睛、鼠尾草绿开衫 + 暖白内搭 + 浅卡其围裙 + 小勺发夹 + 小碗新芽胸针，专业但不冰冷。
图 11　知夏全身立绘：浅栗棕低马尾、暖棕偏绿眼、鼠尾草绿开衫、暖白内搭、浅卡其围裙、小勺发夹、小碗新芽胸针、手持小碗与小勺
图 12　悬浮头像：头肩特写圆形构图，默认只显示头像，点击展开气泡，空白处收起
悬浮球显示与隐藏
首页、配餐结果、记录与详情、知识详情、知识册、勋章墙、我的等普通页显示；拍照与食材确认、餐具校准、菜谱烹饪步骤、健康指标手动填写、NDM 导入冲突、连续输入流程等专注页自动隐藏。所有核心功能仍保留普通页面入口。
主动开口只允许 4 类：每天首开首页一条今日知识、完成配餐/记录后的解释、点亮勋章或重要阶段、必要的健康或操作提示。其余时间保持安静，不跳动、不频繁弹话、不反复催促。
表情与语言
九组表情：默认微笑、思考、解释、开心庆祝、关切提醒、不确定、俏皮、认真、抱歉；计划外饮食固定用倾听/俏皮，健康提示用关切提醒，识别失败用抱歉。语言短句、先肯定、给选择、说边界、不命令，禁用「必须、赶紧、严格按、你又破戒了」等。
图 13　九组表情差分：默认微笑、思考、解释、开心庆祝、关切提醒、不确定、俏皮、认真、抱歉；发色瞳色服装配饰保持一致
七、动效与无障碍
动效只用于三处：页面反馈、角色表情、勋章点亮。普通微动效 1–2 秒，不强制全屏、不阻断操作；里程碑（30/100/365 天）用阶段庆祝卡 + 回顾 + 可选奖励。App 内优先用 Lottie（透明通道），MP4 仅用于首次引导与宣发。
无障碍：系统字体放大、减少动态效果、触控目标 ≥ 44dp、图标 24dp 线性、描边 1.8、圆角端点。状态、进度、图表均「文字 + 图形」双通道，不依赖单一颜色传达含义。
八、双端适配（vivo S7 手机 / Lenovo Y900 平板）
vivo S7（手机）：底部三段导航、单手操作路径短；悬浮球避开底部导航与主按钮；勋章墙双列；拍照识别失败可快捷手改。
Lenovo Y900（平板）：左侧导航栏，首页双栏（主栏下一餐/副栏知识与提醒），记录双栏（左历史列表 / 右营养详情）；配餐流程仍为单任务，不拉住手机界面，悬浮球按大屏放大并调整吸附区。

图 15　Lenovo Y900 平板·记录双栏：左历史列表 + 右单次详情（供能环、四态判定、角色说明、近 14 天趋势）
九、与 PRD 验收要点的对照
温和不清零：日历漏记中性格、计划外饮食走对话而非警告、勋章中断不清零——对应硬原则 1。
干净单一主行动：首页仅「拍照配餐」一个 56dp 主按钮，其余下推——对应硬原则 2。
生活感：色板、描瓷徽章、知夏立绘与表情同源 PRD 设定——对应硬原则 3。
专业不冰冷：配餐结果分「菜谱/营养/额外推荐」三块且额外推荐单独承载、不入合计；疾病场景只做辅助解释并提示就医——对应硬原则 4。
十、待确认事项
平板双栏的分栏宽度阈值（16:10 还是 3:2 优先）；悬浮球默认停靠边是否记忆；立绘与勋章图案是否用于对外宣发（影响输出精度与授权）。
